    Для каждого чата выберите режим. «Два чата» запускает две разные переписки параллельно. Экспериментальный режим делит один чат на два прохода с проверкой перекрытия.

    Для режима двух потоков в самом чате отметьте «Начало», «Середина» и «Конец». Середина должна иметь устойчивые ID и соседние реплики. Без проверенного стыка результат останется двумя черновиками.

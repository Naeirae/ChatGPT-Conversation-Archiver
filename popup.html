Если «Обновить» впервые ничего не делает, один раз запустите Update ChatGPT Archiver.vbs вручную. После этого кнопку можно использовать из интерфейса.

В режиме «Текущая вкладка» архиватор физически прокручивает открытый чат, поэтому до завершения лучше его не трогать. В фоновом режиме отдельная рабочая вкладка используется только для сбора, а исходный чат остаётся свободным. Размышления сохраняются только если соответствующий блок доступен в интерфейсе страницы.
